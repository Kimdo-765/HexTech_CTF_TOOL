### A6. flag 후보 노이즈  ※ 내 처방 두 개가 모두 무효

- **관측**: `eb18a95f4399`의 `meta.flag_candidates[0] = 'DH{[^}'` (Claude 재현).
  출처는 run.log의 shell grep `DH{[^}]*}`이고, matcher가 그 접두 `DH{[^}`를 잡았다.
- **내 최초안 "정규식 메타문자 제외"**: 진짜 flag에 `?` `.` `$` `+`가 흔해 **진짜 flag를 버린다.**
- **내 수정안 "닫는 `}` 없는 후보 제외"**: **효과 0.** `DH{[^}`는 이미 `}`로 끝난다
  (Claude 재현: `endswith('}') = True`). 게다가 explicit marker는 brace 없는 형식도 지원하므로
  전역 brace 필터는 오히려 진짜 marker를 버린다.
- **Codex 처방 (채택)**: generic scan에서 `finditer()`로 span/context를 보존하고,
  match 바로 뒤가 `]`+수량자+`}` 인 **정규식 소스 모양일 때만** 신뢰도를 낮춘다.
  explicit `FLAG_CANDIDATE` marker에는 적용하지 않는다.
- ⚠ 플레이스홀더 자동 폐기는 **금지** — 운영자 방침상 큐레이션은 수동.
