      Settings

      Stored in /data/settings.json. Settings override env vars and apply to the next job (no restart). Leave a field blank to revert to its env/default.

      Agent provider

      Which coding agent drives CTF jobs. Applies to the next job (no restart). Claude uses the Claude Agent SDK; Grok uses Grok Build via ACP; GPT uses Codex CLI with ChatGPT OAuth by default; direct Responses API billing remains an explicit fallback.

      Per-role override (hybrid)

      Run a single role on a different backend from the one above — the point of hybrid operation (e.g. Codex drives the job, Claude judges it). Snapshotted into each job at create time, so a change here applies to the next job and never re-routes one already running. Grok is not a target: it stays a whole-job backend, and a role pointed at it falls back to the job's own provider rather than half-switching.

      OpenAI Codex / GPT credentials & model

      OFF, the default: the cap above is the only authority and nothing touches a slot's cgroup while a job runs. ON lets a job raise its own slot for the run and hand it back afterwards. Usage sampling runs either way.
      Leave this OFF until the host RAM upgrade lands. The safety budget is 70% of the VM, so on a 16 GB VM one slot at 8g is 12 GiB against a 10.9 GiB ceiling and the expansion is simply refused. Raise memory= in .wslconfig first — at 80 GB the budget is 56 GiB and it fits.

      Provider model presets

      Claude, Grok, and GPT each keep their own named presets and active selection. Switching the job provider therefore switches to that provider's active preset automatically. Presets pin per-agent models + reasoning effort. Configurable: main (the CTF agent) and its effort, plus judge (prejudge / postjudge + judge subagent), reviewer (the /retry hint reviewer, separately overridable), recon, debugger, triage, report, and monitor (Claude/Grok only; GPT uses its token-free Timeline). A blank slot = inherit: main + effort fall back to the per-job picker / global Settings values above; judge / report follow main; reviewer follows the judge slot (then main); recon / debugger / triage follow main (cache-aligned); Claude/Grok monitor keeps its cheap default. An explicit per-job model or effort still wins over the preset. ⚠ recon / debugger / triage normally share the main model for cache-prefix alignment — pinning them to a different model works but sacrifices that cache locality (higher cost / latency). Stored in /data/model_presets.json; applies to the next job.

      Cloudflared tunnel — OOB collector

      Opens a public *.trycloudflare.com quick-tunnel to the api and auto-fills the Callback URL in this same section, so remote bots (XSS / SSRF / blind RCE) can beacon back to the built-in collector. Runs as a sibling container, so it survives api redeploys and keeps a stable URL. A dead tunnel stays dead — re-roll manually (Cloudflare rate-limits fresh tunnels).

      ⚠ No auth token set. This tunnel exposes the ENTIRE api to the public internet — including /api/terminal (an interactive shell / RCE) and settings-write. Anyone who learns the URL gets shell on this host. Set an Auth token above to lock everything except the public collector.
